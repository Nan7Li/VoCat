# CellBridge 通话桥

Halo 可以把一部手机或 SIP 软电话接到已经接入的大疆 4G 模块，或接到 SIM 读卡器的 IMS 线路。默认关闭。没有保存并启用之前，不会监听端口，也不会启动 ADB。

本文是部署说明。当前没有在真实大疆模块、读卡器或 OpenWrt 上验证过。

## 验证范围

- 实机未验。下面的行为来自接线、模拟设备和单元测试，没有在真实 QDC507 模块、SIM 读卡器或 OpenWrt 路由器上拨通过电话。
- QDC507 语音 payload 是外部厂商文件。Halo 不内置、不下载该文件。运行时目录里的文件必须和预期哈希一致，并且页面上的启动引导是单独的 opt-in。未启用引导时，只能使用模块上已经运行并通过校验的语音路由。
- 手机、Halo 和模块要能互通。可选路径是局域网、WireGuard 或 Tailscale。SIP 信令是 UDP，RTP 媒体也是 UDP，地址和端口按实际网络填写，没有 TCP 回落。
- OpenWrt 需要 `alsa-utils`（`arecord`、`aplay`）和可用的 `adb`。缺少其中任何一个都不会被显示成就绪。

## 网络

手机和 Halo 需要在同一可达网络，例如局域网、WireGuard 或 Tailscale。通话是 SIP UDP，语音是 PCMU RTP。不要假设存在 SIP ALG 或 TCP 回落。

在电话页填写：

- SIP 监听地址，默认 `0.0.0.0:5060`。这是 Halo 本机接收 REGISTER 和 INVITE 的 UDP 端口。
- 对外地址。手机要能访问的 Halo IP，写进 SIP Contact 和 SDP。监听在 `0.0.0.0` 时必须填写，不能填 `0.0.0.0`。
- RTP 监听地址，默认 `0.0.0.0:40000`。媒体 UDP 使用这一端口。
- 账号和密码。GET 只返回是否已设置密码。保存时留空或保持掩码会沿用旧密码。

手机客户端注册到 `对外地址:SIP 端口`，账号密码与上面一致。只实现语音。SIP MESSAGE 不会被当成短信成功。

SIP 线路和大疆音频是两项独立选择。线路可以是读卡器，音频仍可以是另一台大疆模块。读卡器不需要 ALSA 或 ADB 参数。读卡器只有 IMS 已注册才能通话，未就绪时不会改发蜂窝 AT。

## 大疆音频

只选择设备类型为大疆 4G 的已有设备。浏览器和 SIP 使用同一路 8 kHz PCM。模块已启用 VoWiFi 时，不会因为 IMS 未就绪改走蜂窝。

浏览器通话还要求 HTTPS 或 localhost，以获得麦克风权限；手机通过普通 HTTP 访问局域网 IP 时，浏览器可能无法录音。

普通配置只需要打开大疆音频并选择设备。ALSA 录音和播放设备必须属于这块模块的 USB 口。`default`、PulseAudio 和虚拟声卡会被拒绝，因为主机上存在 `arecord` 并不能证明那就是模块麦克风。

OpenWrt 需要安装 `alsa-utils`（提供 `arecord` 和 `aplay`）以及可用的 `adb`。缺少其中任何一个时，电话页会显示具体原因，状态不会变成就绪。

## QDC507 运行时

大疆语音依赖模块侧的厂商运行时。Halo 用真实 USB 路径匹配设备，不把页面里手填的型号或 VID 当作已经插入的证明。USB 路径使用 `1-1.2` 这种总线端口形式。

高级项默认折叠：

- 运行时目录：放置外部厂商文件的目录。Halo 不内置该文件。
- ADB 路径和 ADB socket。默认 socket 是 `tcp:127.0.0.1:5038`，避免占用系统 adb。
- 启动引导。这是明确 opt-in。关闭时只检查已运行且可验证的模块路由，不会安装文件或启动路由。启用引导时，目录里的厂商文件还需通过 SHA-256 校验。

同一 USB 口换成另一块设备后，原来的通话会被结束，且不会向新设备发送挂断或引导命令。

运行时目录应包含以下三个文件；哈希固定于所适配的 CellBridge 提交，不能用其他版本文件代替：

| 文件 | SHA-256 |
| --- | --- |
| `mavo-pcm-bridge.armv7` | `88d47c15e61d1428a59c821fed804c2e6490e82859a085062f21966b58d167fc` |
| `qdc507_aprv3.ko` | `3d82d3dec4f1e323201bba87156df9d41438e08314097353f2607f9117211d4a` |
| `qdc507_voice.ko` | `ed3821682d5309969a01c764192c83feff9669c61ef237c69475cd1619cf296c` |

当前模块检测要求内核 `3.18.44`、模块侧声卡 `mdm9607-tomtom-i2s-snd-card`，同时核对真实 USB 与 ADB 设备。仅“大疆 4G”这个名称不能证明兼容。

## 录音与短信

蜂窝通话录音由通话控制器写入现有通话记录，格式是 8 kHz 立体声 WAV。下载仍走原来的通话记录接口。没有真正保存的文件不会显示为已有录音。

短信继续用现有网页和 Telegram，不走 SIP MESSAGE。

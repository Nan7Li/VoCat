# J3160 / N5105 / Debian 13 部署 Halo + CellBridge

J3160 和 N5105 都是 Linux x86_64，使用同一份 `GOAMD64=v1` 程序。默认 `halo` 分支包含融合代码，集成开发分支是 `integration/vocat-cellbridge`。SIP 和大疆音频默认关闭。当前只完成软件测试，尚未在 NAS 或电话硬件上验证。程序安装成功、模块 UAC/ADB 就绪、大疆音频验证成功，是三件不同的事。本文中的 Docker 命令需要 NAS 已安装 Docker Engine 和 Compose 插件。

## Docker 部署

在 NAS 上检出或解压集成源码，进入项目根目录。使用 `compose.nas.yml`，它构建本项目的 Halo 集成镜像。仓库原来的 `docker-compose.yml` 默认拉取上游 VoCat 镜像，不包含此次融合代码。

```sh
mkdir -p nas-data
./scripts/fetch-qdc507-runtime.sh --output-dir ./qdc507-runtime
docker compose -f compose.nas.yml build
```

`fetch-qdc507-runtime.sh` 只从 MaVo 固定提交 `0443dfdaf8aec086fd76ba2ee9152fd908114524` 的 `Resources/ModuleVoice` 下载三个运行文件并校验 SHA-256。不要在它之前创建 `qdc507-runtime`，目标目录必须还不存在。没有这三个文件时不要把大疆语音说成可用。

首次使用空数据库时，初始化管理员。密码只在 NAS 终端输入，经标准输入传给程序，管理员凭据保存在 SQLite 中：

```bash
read -rsp 'Halo 管理员密码: ' HALO_SETUP_PASSWORD
printf '\n'
printf '%s\n' "$HALO_SETUP_PASSWORD" | docker compose -f compose.nas.yml run --rm -T \
  --entrypoint /opt/vocat/bin/vocat halo bootstrap-admin
unset HALO_SETUP_PASSWORD
```

已有 Halo 数据应先停止原实例并备份整个数据目录，再将该目录配置为 `nas-data` 挂载源；已有管理员的数据库跳过初始化。备份用于回退，因为本分支包含数据库迁移。避免多个实例同时访问相同设备或数据文件。

```sh
docker compose -f compose.nas.yml up -d
docker compose -f compose.nas.yml logs --tail=100 halo
curl --fail http://127.0.0.1:7575/healthz
```

浏览器访问 `http://NAS地址:7575` 完成设备设置。浏览器语音需要 HTTPS；SIP 客户端通话不要求浏览器麦克风权限。停止服务使用 `docker compose -f compose.nas.yml down`，这条命令保留本机 `nas-data` 数据目录。

## 硬件检查

容器镜像包含 `arecord`、`aplay`、`adb`、`pcscd` 和 CCID 驱动。配置使用主机网络以及 `/dev`、`/sys` 挂载，支持实际 USB 设备与声卡发现。宿主机 Linux 仍须识别模块及其 USB 声卡；镜像内安装 ALSA 工具不能替宿主机补齐内核驱动。

```sh
docker compose -f compose.nas.yml exec halo sh -c 'uname -m; command -v adb; command -v arecord; command -v aplay; command -v pcscd'
docker compose -f compose.nas.yml exec halo arecord -l
docker compose -f compose.nas.yml exec halo aplay -l
```

容器内运行时目录填写 `/opt/halo/qdc507`。文件、哈希、匹配的模块内核与声卡要求见 [CellBridge 通话桥](CellBridge.zh-CN.md)。先确认模块和声卡，再按实际设备开启大疆音频与启动引导。镜像里装了 ALSA 工具，也不等于宿主机已经认出模块声卡。

SIM 读卡器通过 PC/SC 完成 SIM 认证，通话走已注册的 IMS；仅发现 USB 读卡器不等于 IMS 已就绪。宿主机若已有 `pcscd` 或其他程序持有读卡器，先解决设备占用再验证容器中的读卡器路径。

## iPhone 远程通话

先在局域网完成双向通话和录音验证，再把 iPhone 通过 WireGuard 等可达 VPN 接入 NAS。电话页分别设置 SIP 线路与大疆音频设备；读卡器 IMS 线路无需开启大疆音频。

SIP 默认 UDP `5060`，RTP 默认 UDP `40000`；对外地址填 iPhone 实际能访问的 NAS 局域网或 VPN 地址。HTTPS 网页反向代理只覆盖网页入口，不能自动代转 SIP/RTP UDP。

在 iPhone 的 SIP 客户端填写该地址、端口及电话页的账号密码。当前没有实现 iOS 原生 App 或推送唤醒；锁屏和后台来电需要结合所用 SIP 客户端验证。远程拨号、本地通话、锁屏来电和延迟都需要实际测试。

## 预编译 amd64 程序

### 一套部署与内部更新

Halo、VoCat 与 CellBridge 已集成为一个程序和一个原生服务；大疆运行文件由同一安装流程准备，无需单独部署 CellBridge。

在 Debian 13 的 NAS 终端中执行（需要能访问 GitHub）：

```bash
sudo bash -o pipefail -c 'apt-get update && apt-get install -y curl ca-certificates && curl -fsSL https://raw.githubusercontent.com/Nan7Li/VoCat/halo/scripts/deploy-cellbridge-nas.sh | bash'
```

入口会选择已发布的融合版、校验整包 SHA-256、安装依赖、准备大疆运行文件、初始化或保留管理员，再启动唯一的 Halo 服务。安装后访问 `http://NAS的IP:7575`。首次安装需在终端输入管理员密码；已有管理员不会重置。下载或文件校验失败会停止安装。

系统设置中的“自动检查更新”和“自动安装更新”直接控制程序更新。新 NAS 安装默认每 6 小时检查融合版并在无通话时安装；已有更新偏好优先，关闭自动安装的用户可继续在页面点“检查更新 / 应用更新”。程序更新会备份数据库并保留旧程序，保留账号、配置、录音和大疆运行文件；更新后需要重新登录。

融合版使用 `cellbridge` 更新通道，只接受本仓库的融合版发布，避免普通 Halo 版本覆盖 CellBridge。向 GitHub 的 `halo` 分支推送代码后，`Halo CellBridge NAS` 工作流会运行测试、构建并发布程序、SHA256SUMS 和 NAS 包；NAS 从发布产物更新，不直接运行未构建的 Git 源码。失败的测试或构建不会发布新版本。大疆 UAC / ADB / 双向通话仍须接模块完成配置和验收。

可先运行下载的脚本加 `--check-only`，它不会安装依赖、下载文件或改服务。原生部署支持内部更新，Docker 方式仍需更新容器镜像。

发布包带有 `halo-linux-amd64`、`source/`、`SHA256SUMS` 和 `./install`。二进制通过 `CGO_ENABLED=0 GOARCH=amd64 GOAMD64=v1` 构建，J3160 和 N5105 都能用。网页资源已嵌入。

在解压后的发布包目录：

```sh
sha256sum -c SHA256SUMS
sudo ./install --fetch-runtime
bash source/scripts/check-cellbridge-nas.sh
```

已有运行文件时使用 `sudo ./install --runtime-dir /path/to/runtime`。`--fetch-runtime` 会先安装下载依赖，再从固定来源获取文件并逐一校验。`./install` 会安装 `alsa-utils`、`adb`、`pcscd`、`libccid`、`ca-certificates`、`iproute2` 、`sqlite3` 和 `curl`，校验二进制，停止已有原生服务，备份 `/opt/halo` 的数据、二进制和服务单元，再原子替换程序。空数据库时从标准输入初始化管理员；已有管理员不会读取或重置密码。

密码只走本机标准输入。直接执行安装命令即可在终端里不回显地输入；已有管理员不会读取密码。非交互且没有密码时安装失败，不会写入默认密码。

原生数据文件是 `/opt/halo/data/halo.db`。三个运行文件安装到 `/opt/halo/qdc507`，电话页的运行文件目录也填这一路径，ADB socket 填 `tcp:127.0.0.1:5038`。录音和播放设备按 `check-cellbridge-nas.sh` 打印的实际声卡填写，`plughw:1,0` 只是界面初始占位。

没有运行文件时，`sudo ./install` 仍可安装 Halo 和读卡器 IMS，但会明确写出“大疆语音文件未配齐”。这不是接上即用，也不能把健康检查通过理解成模块语音已经可用。

原生程序和 Docker 只能选一种。安装器发现 `halo-cellbridge` Compose 项目或同名容器正在运行时会停止，不会再启动一份 systemd 服务。`check-cellbridge-nas.sh` 只做只读诊断，不刷写模块，也不打开 ADB。

依赖包名核对：[Debian 13 ALSA 工具](https://packages.debian.org/trixie/alsa-utils)、[ADB](https://packages.debian.org/trixie/adb)、[CCID 驱动](https://packages.debian.org/trixie/libccid)、[sqlite3](https://packages.debian.org/trixie/sqlite3)。Docker 内使用 Alpine 的 [alsa-utils](https://pkgs.alpinelinux.org/package/v3.20/main/x86_64/alsa-utils) 和 [android-tools](https://pkgs.alpinelinux.org/package/v3.20/community/x86_64/android-tools)。
